## 为什么又写博客

因为想法需要一个落地的容器。

以前写东西散在各个平台，删号、改版、限流，最后都变成了 404。放在自己的域名下，哪怕只有一个人看，至少它是活的、是能改的、是带得走的。

## 这里会写什么

大概是这几类：

- **技术笔记**：踩过的坑、读过的源码、能直接复制的配置
- **阅读摘记**：书和文章里值得回看的段落
- **杂想**：写作、效率、生活里那些"想清楚了但还没说清楚"的事

不追热点，不写标题党。写完之后放一阵子再回头改，改到我说得清为止。

## 这个站怎么搭的

就是很普通的静态站：

```bash
npm install
npm run dev     # 本地 http://localhost:4321
npm run build   # 产出 dist/
```

每一篇文章就是 `src/content/posts/` 下的一个 `.md` 文件，推上去自动构建部署。

> 简单的东西不容易坏。

之后大概会慢慢加上：标签页、归档页、搜索。先让第一篇发出来，别的再说。
